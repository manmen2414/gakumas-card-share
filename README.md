# gakumas-card-share
学マス名刺共有ページ (Github Pages公開用)

> [!warning]
> このページは非公式の自己紹介ページで、該当ゲームの関係者様は一切関与していません。

...あと1時間程度で組んだのでコードがすごく雑です。

## 自分用にカスタマイズする
1. クローンまたはフォーク
2. `qr.png`を自身のP-IDを示すQRコードに置き換える。
3. `card.png`を自身の名刺などに置き換える。
4. `index.html`上部のPIDを自身のP-IDに置き換える。
5. `index.html`上部のGAKUMAS_URLを以下の手順で取得したアプリオープンリンクで置き換える。

## アプリオープンリンクの取得
1. スマホ版学マスで、メニュー → 名刺 → 共有 の順に移動し、出てくるリンクを取得する。
2. `https://app.adjust.com/1enrh1ad?deeplink_js=1&deep_link=`を削除する。
3. 残りのURLをURL特殊文字デコードする。
4. デコードしたURLにスマホのブラウザからアクセスし、ゲームが起動・名刺ページに遷移すれば取得完了。
